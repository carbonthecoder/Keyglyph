# Keyglyph

> Transform keystrokes into geometric vector signatures.

An aesthetic web tool that tracks the exact coordinates of your keyboard layout and translates typed text into continuous, scalable vector signatures.

---

### Features

- **Keyboard Geometries**: Real-time vector path tracing across QWERTY, Dvorak, Colemak, AZERTY, and QWERTZ layouts.
- **Smoothing Algorithms**: Linear, Simple curve, Quadratic Bezier, Cubic Bezier, and Catmull-Rom splines.
- **Vercel Design Language**: Minimalist monochrome interface with pixel-perfect Light and Dark themes.
- **Dynamic Fading**: Virtual keypad smoothly disappears when idle to isolate the signature artwork.
- **Mobile First**: Fluid responsive scaling for iPhones, Android, and touch devices.
- **Vector Exports**: High-resolution `.svg` and 2x retina `.png` export engine.
- **Synthesized Audio**: Web Audio API mechanical switch feedback.

---

### Quickstart

```bash
# Clone the repository
git clone https://github.com/carbonthecoder/Keyglyph.git

# Enter directory
cd Keyglyph

# Install dependencies
npm install

# Start local dev server
npm run dev
```

---

### Deploy to Vercel

```bash
npm run build
```

Or import the repository directly into [Vercel](https://vercel.com) for instant zero-configuration deployment.
